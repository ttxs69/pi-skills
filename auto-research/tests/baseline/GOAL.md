# Research goal

Investigate how the leading LLM agent frameworks handle context-window
management in long-horizon tasks (multi-hour or multi-day sessions).
Focus on what was published or shipped in the last 18 months.

## Scope
- Frameworks: LangChain, LlamaIndex, OpenAI Assistants API, Anthropic Agent SDK, AutoGen, CrewAI
- Compare: compaction strategies, summarization, sliding-window approaches, memory hierarchies

## Out of scope
- Pure RAG chunking (covered elsewhere)
- Embedding model selection
- Vector store internals
